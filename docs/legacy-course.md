# 补充练习与配置材料

正式章节均按教材章号放在Textbook/Ch01—Ch13。请从[章节导航](textbook/README.md)进入，不需要根据历史模块编号猜测文件。

- 引言陈述核对：lean/Textbook/IntroductionExamples.lean、rocq/Textbook/IntroductionExamples.v。
- 完整邻域与平方函数：lean/Textbook/Ch04/AISquare.lean。
- 第三章的更多例子：Textbook/Ch03/DefinitionExamples、WorkedLimits、RestrictedExamples；Rocq库对照在Textbook/Ch03/CoquelicotBridge.v。
- Theories/ProjectBase与examples/ProjectUse是附录多文件练习，不属于某一数学章。
- AppendixA/是安装检查例子；templates/需复制到独立练习目录后使用，不能覆盖教材项目配置。

在仓库根目录运行make check；编辑器与独立例子使用方法见[安装指南](../appendix-a/README.md)。片段文本用于阅读，完整证明以相应.lean或.v文件为准。
