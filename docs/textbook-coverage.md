# 十三章代码覆盖与使用边界

本书每章均有Lean与Rocq的可编译入口，合计26个。入口导入统一项目中的实际实现，不是空白占位文件。目录与命名空间前缀已经按教材章号统一，以 `Textbook/ChXX/All` 和 [章节导航](textbook/README.md) 为准。

逐条数学条目的核对状态见[textbook-item-map.json](textbook-item-map.json)。其中matched表示已核对对应，pending表示尚未逐条核对，不等于没有任何相关库代码。

“每章都有代码”表示提供有数学内容的代表性实现，**不表示每一个纸面定义、引理、例题和练习都已用两种语言完整形式化**。下表把当前覆盖和边界同时列出。

## 怎样检查

从代码仓库根目录执行 `make check`，会构建 Lean 的教材及附录模块、检查独立例子，并构建 Rocq 的教材模块、Coquelicot 示例和路径配置模板。逐章运行 `make chapter CHAPTER=08`，只用一种语言则运行 `make chapter-lean CHAPTER=08` 或 `make chapter-rocq CHAPTER=08`。先按 README 安装固定版本和依赖。

当前本地核验使用Lean 4.35.0 / Mathlib v4.35.0、Rocq及Stdlib 9.2.0、Coquelicot 3.4.5、OCaml 4.14.1，使用现有依赖与增量缓存；不冒称全新机器安装或远程GitHub CI均已测试。详情见[构建核验](build-validation.md)。
