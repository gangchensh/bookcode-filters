附录 A.12：Lean 与 Rocq 的版本切换

以下按教材出现顺序收录命令、配置或证明源码。
请先阅读对应小节，确认执行平台、目录和版本。不要把整个文件作为脚本运行。
标为“输出示例”的内容只用于核对，不输入终端。
示例路径、用户名和版本占位符应按实际替换。

===== 示例 1 =====
输入位置：Ubuntu 终端
目录或对象：任意目录；可选的版本操作示例，default 会修改默认值

elan toolchain install leanprover/lean4:v4.31.0
elan default leanprover/lean4:v4.31.0
elan run leanprover/lean4:v4.31.0 lean --version
lake +leanprover/lean4:v4.31.0 --version

===== 示例 2 =====
输入位置：Ubuntu 终端
目录或对象：待比较的同一 Lean 项目根目录；两个终端都执行

pwd
cat lean-toolchain
type -a lean lake
elan show
lean --version
project_toolchain=$(tr -d '\r\n' < lean-toolchain)
elan run "$project_toolchain" lean --version

===== 示例 3 =====
输入位置：Ubuntu 终端
目录或对象：当前 Lean 项目根目录；保留项目文件与终端原有版本选择

project_toolchain=$(tr -d '\r\n' < lean-toolchain)
elan run --install "$project_toolchain" lean --version
elan run "$project_toolchain" lake --version
elan run "$project_toolchain" lake build

===== 示例 4 =====
输入位置：Ubuntu 终端
目录或对象：CalculusLean 根目录；已按本项目的 lean-toolchain 赋值

elan run "$project_toolchain" lake env lean MathlibSmoke.lean

===== 示例 5 =====
输入位置：Ubuntu 终端
目录或对象：当前 Lean 项目根目录；只调整当前终端及随后启动的程序

project_toolchain=$(tr -d '\r\n' < lean-toolchain)
elan toolchain install "$project_toolchain"
lake_path=$(ELAN_TOOLCHAIN="$project_toolchain" elan which lake)
export PATH="$(dirname "$lake_path"):$PATH"
unset ELAN_TOOLCHAIN
hash -r
lean --version
lake --version

===== 示例 6 =====
输入位置：Ubuntu 终端
目录或对象：待升级的 Git 项目根目录；已保存并提交工作，目标分支名尚未使用

git status --short
git switch -c upgrade-lean-4.35
curl -fL https://raw.githubusercontent.com/leanprover-community/mathlib4/v4.35.0/lean-toolchain -o lean-toolchain

===== 示例 7 =====
输入位置：项目配置内容
目录或对象：升级分支中的 lakefile.toml；替换已有的 mathlib 依赖条目

[[require]]
name = "mathlib"
scope = "leanprover-community"
rev = "v4.35.0"

===== 示例 8 =====
输入位置：Ubuntu 终端
目录或对象：升级分支的项目根目录；依赖声明已修改并保存

project_toolchain=$(tr -d '\r\n' < lean-toolchain)
elan toolchain install "$project_toolchain"
elan run "$project_toolchain" lake update

===== 示例 9 =====
输入位置：Ubuntu 终端
目录或对象：升级分支的 mathlib 项目根目录；仅在需要补齐新版本缓存时运行

elan run "$project_toolchain" lake exe cache get

===== 示例 10 =====
输入位置：Ubuntu 终端
目录或对象：升级试验项目根目录；缓存准备已结束，不并行更新与构建

elan run "$project_toolchain" lake build
elan run "$project_toolchain" lake env lean MathlibSmoke.lean

===== 示例 11 =====
输入位置：Ubuntu 终端
目录或对象：任意目录；新环境示例，已有同名 switch 时不重复创建

opam switch create calculus-rocq-9.2 ocaml-base-compiler.4.14.2
eval "$(opam env --switch=calculus-rocq-9.2 --set-switch)"
opam repo add rocq-released https://rocq-prover.org/opam/released
opam update
opam install rocq-prover rocq-core=9.2.0
rocq -v

===== 示例 12 =====
输入位置：Ubuntu 终端
目录或对象：旧 Rocq 项目根目录；下列操作只记录已有环境，不修改 switch

old_switch='calculus-rocq'
mkdir -p env-records
opam switch export env-records/rocq-before-upgrade.export --switch="$old_switch" --full
opam list --switch="$old_switch" --installed > env-records/rocq-packages.txt
opam pin list --switch="$old_switch" > env-records/rocq-pins.txt

===== 示例 13 =====
输入位置：Ubuntu 终端
目录或对象：目标 switch 已创建并安装 Rocq 9.2.0；仅预览可选包的相容安装方案

new_switch='calculus-rocq-9.2'
opam install --switch="$new_switch" --dry-run rocqide vsrocq-language-server coq-coquelicot

===== 示例 14 =====
输入位置：Ubuntu 终端
目录或对象：升级试验副本的 Rocq 根目录；已有 _CoqProject，clean 只用于清理本副本的生成结果

eval "$(opam env --switch="$new_switch" --set-switch)"
command -v rocq
rocq -v
rocq makefile -f _CoqProject -o RocqMakefile
make -f RocqMakefile clean
make -f RocqMakefile

===== 示例 16 =====
输入位置：Ubuntu 终端
目录或对象：任意目录；实际 switch 名按 opam switch list 替换，仅读取

opam switch list
switch_name='calculus-rocq-9.2'
switch_prefix=$(opam var prefix --switch="$switch_name")
printf '%s\n' "$switch_prefix"
du -sh "$switch_prefix"
opam list --switch="$switch_name" --installed

===== 示例 19 =====
输入位置：Ubuntu 终端
目录或对象：任意目录；仅在确认该工具链无项目和编辑器依赖后执行，占位符必须替换

old_toolchain='OLD_TOOLCHAIN_FROM_LIST'
elan toolchain uninstall "$old_toolchain"
elan toolchain list

===== 示例 20 =====
输入位置：Ubuntu 终端
目录或对象：任意目录；已核对旧switch无项目依赖并完成环境记录，两个占位符均须替换且名字不同

keep_switch='KEEP_SWITCH_FROM_LIST'
old_switch='OLD_SWITCH_FROM_LIST'
eval "$(opam env --switch="$keep_switch" --set-switch)"
opam switch set "$keep_switch"
opam switch remove "$old_switch"
opam switch list
