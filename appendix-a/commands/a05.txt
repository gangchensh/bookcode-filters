附录 A.5：Ubuntu 命令入门

以下按教材出现顺序收录命令、配置或证明源码。
请先阅读对应小节，确认执行平台、目录和版本。不要把整个文件作为脚本运行。
标为“输出示例”的内容只用于核对，不输入终端。
示例路径、用户名和版本占位符应按实际替换。

===== 示例 1 =====
输入位置：Ubuntu 终端
目录或对象：任意已有目录；从 cd 行开始进入练习目录

pwd
ls
ls -a
cd /mnt/d/calculus-work
mkdir -p command-practice
cd command-practice
pwd
cd ..

===== 示例 2 =====
输入位置：Ubuntu 终端
目录或对象：任意目录；安装系统软件

sudo apt update
sudo apt install git curl
git --version
curl --version

===== 示例 3 =====
输入位置：Ubuntu 终端
目录或对象：练习目录 /mnt/d/calculus-work

curl -fL https://raw.githubusercontent.com/leanprover/elan/master/README.md -o elan-readme.md
ls -l elan-readme.md
less elan-readme.md

===== 示例 4 =====
输入位置：Ubuntu 终端
目录或对象：练习目录 /mnt/d/calculus-work

printf '%s\n' 'calculus' > course-name.txt
cat course-name.txt
course_name=$(tr -d '\r\n' < course-name.txt)
printf '%s\n' "$course_name"

calculus
calculus

===== 示例 6 =====
输入位置：Ubuntu 终端
目录或对象：任意目录；先查看系统资源

df -h / /mnt/d
free -h
nproc

===== 示例 7 =====
输入位置：Ubuntu 终端
目录或对象：已有的 Lean 项目根目录；安装后按需查看用户工具与项目磁盘占用

du -sh "$HOME/.elan" "$HOME/.opam" .lake 2>/dev/null

===== 示例 8 =====
输入位置：Windows PowerShell
目录或对象：任意目录；编辑当前 Windows 用户的 WSL 配置

notepad "$env:USERPROFILE\.wslconfig"

===== 示例 9 =====
输入位置：配置文件
目录或对象：Windows 用户主目录的 .wslconfig；示例须按机器资源调整

[wsl2]
memory=8GB
processors=4
swap=4GB

===== 示例 10 =====
输入位置：Windows PowerShell
目录或对象：保存工作后运行；停止全部 WSL，再启动 Ubuntu

wsl --shutdown
wsl -d Ubuntu

===== 示例 11 =====
输入位置：Ubuntu 终端
目录或对象：任意目录；只检查资源限制功能是否可用

ps -p 1 -o comm=
systemd --version
stat -fc %T /sys/fs/cgroup
systemctl --user show-environment

===== 示例 12 =====
输入位置：Ubuntu 终端
目录或对象：准备运行任务的项目目录；启动受限的 Bash 子终端

systemd-run --user --scope \
  -p MemoryHigh=3G -p MemoryMax=4G \
  -p MemorySwapMax=1G -p CPUQuota=200% \
  -p OOMPolicy=kill bash

===== 示例 13 =====
输入位置：Ubuntu 终端
目录或对象：开源代码根目录；两个例子任选其一

bash appendix-a/scripts/run-limited.sh bash
bash appendix-a/scripts/run-limited.sh make lean

===== 示例 14 =====
输入位置：Ubuntu 终端
目录或对象：任意目录；查看当前启动的内核日志末尾

sudo journalctl -k -b -n 80 --no-pager
